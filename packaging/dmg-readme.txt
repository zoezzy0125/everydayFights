everydayFights — EdgeTodo-based macOS customization

Quit any existing EdgeTodo, then drag EdgeTodo.app into Applications.
Allow Reminders access to view and edit your lists.
This build is ad-hoc signed and not Apple-notarized. Run only if you trust the source.
Do not disable system security protections.

使用说明 / Documentation: https://github.com/zoezzy0125/everydayFights
Upstream / 原项目: https://github.com/tangbonze/EdgeTodo
The app retains EdgeTodo's bundle ID for compatibility; do not run both variants at once.
