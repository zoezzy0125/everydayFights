# everydayFights

把每天的小事，一件件打败。☀️

**everydayFights 是一个轻量的 macOS 桌面侧边待办小工具**：不是浏览器插件，也不是 iPhone App。平时隐藏在屏幕边缘，唤出后可以安排今天的任务、追踪短期目标、查看截止倒计时。

> 当前发布的是基于 EdgeTodo v1.3.2 的系统提醒事项定制版 `1.3.2-local.14`，不是本仓库早期的独立 JSON 存储实现。旧提交保留供历史查阅。

- **截止日期是今天的未完成 Short-term Goal** 会自动显示在 Daily，仍是同一个提醒而非副本，两处完成状态一致。不修改分类、日期或目标历史。无日期及非当天截止的目标不加入；当日到期并于当日完成的目标会在完成区保留到午夜；过期目标仍在 Goal，不自动顺延到 Daily。可见面板每 30 秒刷新，重新打开也会刷新。

## 功能

- **Daily Todo**：打开默认进入今日清单，空白日有简短鼓励语。
- **自动顺延**：昨天及更早未完成的 Daily 自动显示在今天，直到完成。不复制任务。跨日未完成任务标红，并显示负数倒计时（如 `-1 天 · 已延期`），保留原日期；当天任务仍显示“今天”。
- **Short-term Goal**：适合论文、项目、旅行等需要截止日期的目标；原有提醒事项默认在这里。
- **可点选日历**：直接选年、月、日，单独填写时间，点 Today 回到今天。
- **截止倒计时**：按本地日历天数计算，不是简单除以 24 小时。
- **紧迫表情**：短期目标超过 30 天 😌、8–30 天 🏃、2–7 天 🔥、今天或明天 👿、已到期 🚨；今日 Daily 用 🚨。
- **自选 emoji**：给工作、论文、生活任务选一个自己的图标，与紧迫表情并排显示。
- **三级任务树**：顶层目标 → 子任务 → 子子任务，最多三级；拒绝循环归属和超过三级的移动。
- **Daily 关联目标**：已有 Daily 可关联到大事项，在今日页与目标树展示同一提醒，完成状态一致。
- **Daily History**：按原任务日期查看下级 Daily 的完成/未完成情况，单独展示真实完成时间。
- **随用随收**：点击界面外收起面板，未保存的草稿会保留。
- **系统提醒事项**：直接使用 macOS Reminders；无需另注册账号。

## 系统要求

- macOS 13 或更新版本。
- 当前构建脚本面向 Apple Silicon（M 系列芯片）；尚未验证 Intel Mac。
- 允许读取和修改系统“提醒事项”。语音输入是可选功能，另需麦克风与语音识别权限。

## 安装与首次使用

当前提供源码构建方式，尚未提供这个版本的预编译安装包。请按下面的“本地构建”步骤生成应用，再手动安装。

**仓库名是 everydayFights；为保持既有设置兼容，应用包仍叫 `EdgeTodo.app`，显示名为“侧边待办”或 EdgeTodo，bundle ID 为 `com.tangbonze.edgetodo`。不要同时运行上游版和本定制版。**

应用通常在菜单栏和屏幕侧边显示，不在 Dock 中常驻。首次打开请允许提醒事项访问；若之前拒绝，可到“系统设置 → 隐私与安全性 → 提醒事项”重新开启。

本地构建采用 ad-hoc 签名，尚未经过 Apple 公证。只运行你信任的来源；不要关闭 Gatekeeper 或批量移除隔离属性。系统阻止启动时，先确认来源，再按 macOS 提供的安全流程处理。重新编译可能触发再次授权。

## 怎么用

### 1. 打开清单

将鼠标移到屏幕边缘的灰色拉手，或按 **⌥ Option + ⌘ Command + T**。默认打开 Daily Todo；已有草稿时保留草稿所属分区。

### 2. 新建任务

在当前分区进入输入行，填写任务内容、选择日历日期及时间，点击 **Add** 或按回车保存。日期顶部可以直接改月份和年份，**Today** 选中今天并保留时间。设置日期时间时也会为系统提醒事项设置对应提醒。

### 3. 查看与完成 Daily

今日 Daily 显示 🚨。过去未完成的任务自动带入今天，并标注原日期；已完成的和未来计划可通过 **History & plans** 查看。点击任务左侧圆圈完成任务。

**顺延是本工具的展示行为，不会改系统提醒事项的原截止时间或闹钟，也不会每天重新通知。** 在苹果提醒事项 App 中仍可能看到原截止日期。

### 4. 管理短期目标

切换到 **Short-term Goal** 查看截止倒计时。任务按截止时间从早到晚排列，无日期的放后面。右键任务可编辑提醒日期，或选择 **Move to Daily Todo / Move to Short-term Goal** 改分区。

### 5. 自选图标

右键任务 → **Task emoji** → 选择预设，或 **Custom…** 输入自己的 emoji。自选图标与自动紧迫图标并列，不会替代截止提醒。

### 6. 添加小事项

右键大事项 → **Add Subtask…**，填写子任务并保存。可连续添加多个；每个都能独立完成。父任务完成不会自动完成所有子任务。按 Esc 退出子任务输入。

任务树最多三级（顶层算第一级），第三级不能再添加子任务。移动带子任务的整棵子树时也会检查深度，不能把任务挂到自己或自己的后代下。

### 7. 将今天的任务关联到大目标

右键已有 Daily → **Link to Task… / 关联到大事项…** → 选择所属目标或子任务。选择列表仅显示未完成的 Short-term 任务，不显示 Daily 或已完成历史任务，并保留三级层级和防循环限制。关联只改归属，不改 Daily 分类、日期、提醒闹钟或完成状态；两处是同一提醒，不会复制一份。今日页显示归属路径，目标树显示该 Daily。也可以直接右键大目标 → **Add Daily Task… / 添加 Daily 小事项…**，创建日期默认选今天。

右键 **Unlink from Parent / 解除归属** 即可取消关系，任务本身和普通备注保留。目标候选限定在当前同一系统提醒列表；不要移动相关任务到不同的提醒列表，否则本工具可能无法解析原归属。

### 8. 查看大事项的 Daily 历史

右键大事项 → **Daily History… / Daily 历史记录…**，查看当前关联的所有下级 Daily，按原任务日期分组。未设置截止日期时明确使用创建日期，日期缺失时显示未知；每项标出未完成或已完成，完成时间仅取系统实际记录，缺失时显示“未记录完成时间”。这不是每日工作时长或操作审计日志，不会声称未完成任务已经做过。

目标完成后，可通过 Goal 页顶部 **History · include completed goals** 找到它，再查看历史。解除/更改归属会改变该目标的历史集合，但不会删除任务。Daily 自动顺延不改原日期，因此不会伪造每天的新工作或完成记录。

## 数据、隐私与兼容性

- 内容存放在系统提醒事项中。是否跨设备同步取决于你所选列表对应的账号及 iCloud 设置。
- Daily 分类、自选 emoji、父子归属使用提醒事项备注中的 `EdgeTodo-Section`、`EdgeTodo-Emoji`、`EdgeTodo-Parent` 标记；保留普通备注文字，请勿手动删除这些标记，除非想取消对应关系。
- **子任务是兼容分组，不是苹果原生子任务**：本工具里缩进展示，在苹果提醒事项 App 中为独立事项。父子关联依赖当前 Mac 的提醒标识，不保证另一台 Mac 同样自动分组。
- 不将你的真实任务、截图、账号信息或本地数据库放进此代码仓库。
- 语音功能沿用上游实现；支持本地识别时启用本地识别要求，不能承诺所有系统条件下都离线。无需语音时不授予相关权限即可。

## 本地构建（开发者）

需要 Xcode Command Line Tools 和 Apple Silicon Mac。先下载本仓库：

```bash
git clone https://github.com/zoezzy0125/everydayFights.git
cd everydayFights
./scripts/test.sh
./build.sh
# 输出 dist/EdgeTodo.app
./package.sh
# 输出 DMG
```

不需要安装第三方包。构建完成后，先退出正在运行的 EdgeTodo，再将 `dist/EdgeTodo.app` 拷贝到“应用程序”。构建脚本本身不会安装、启动应用或读取你的真实事项；测试只使用合成对象，不保存系统提醒。重新签名后可能需要再次授权提醒事项。

## 删除任务 / Delete tasks

点击任务行末尾垃圾桶（或右键“删除”），确认框默认取消。确认删除后，会删除对应的 Apple 系统提醒事项及其闹钟，不标记完成，也不会出现在 Daily、Goal 或 History。没有应用回收站或撤销，请按永久删除处理：系统是否提供恢复取决于系统版本及账户，不保证可以恢复。

删除父任务只解除直接小任务的归属，保留这些小任务及更深层关系，不会级联删除。操作失败会显示错误并重新读取系统状态。不会自动删除任何现有任务；每次删除均需用户确认。

Use the row's trash button or context-menu Delete. Cancel is the default. Confirming deletes the corresponding Apple reminder and its alarms, without marking it completed or leaving a History entry. There is no in-app Trash or undo. Treat deletion as permanent; system recovery depends on the OS/account and is not guaranteed. Direct subtasks are preserved and unlinked; deeper links remain. No tasks are deleted automatically.

### Daily 排序与完成记录
- 当天完成的 Daily 会留在最下方「今天完成」中，打勾并划线；之前顺延过来的任务也按实际完成日期保留到当天结束。第二天不再占据今日清单，历史记录仍保留。当日到期的 Goal 当天完成后也保留在完成区。
- 未完成项默认按添加时间排列；拖动 **⋮⋮** 拉手，放到另一未完成项上半部/下半部即可调整顺序。越靠前淡紫底色越深，逾期仍以红色文字区分，完成项不参与排序。
- 可用键盘聚焦拉手后按 ↑/↓、VoiceOver 操作，或右键「提高/降低优先级」，不必拖动。
- 手动顺序保存在本机，刷新和重启后仍保留。新进入清单的任务追加在已有排序后面；完成或暂时离开今日的任务保留原相对位置。不会改 Apple 提醒事项的优先级、日期和备注，不跨 Mac 同步。
- Daily 平铺以允许子任务独立排序，同时显示归属路径；Goal 树与历史关系不变。删除后的排序 ID 可能保存在本地偏好中，但不会重新创建任务。
